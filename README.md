# Mercado da Casa

App de bolso para controlar a comida da casa: preços do mercado, lista de compras e balanço do mês. Dieta editável.

Abrir: https://kaleb-nunes.github.io/mercado-da-casa/

- Os dados ficam no próprio celular (armazenamento do navegador). Use **Fazer backup** uma vez por mês.
- No iPhone: Safari → Compartilhar → Adicionar à Tela de Início.
